# Техническое задание (v1.0)
**Тема проекта:** Мобильное приложение «Заметки»  
**(группа 505с11):** Плотников Андрей, Подзоров Валерий  

## 1. Цель приложения
Разработка простого, быстрого и надёжного мобильного Android-приложения для создания, хранения, редактирования, поиска и экспорта текстовых заметок без необходимости подключения к интернету.

## 2. Целевые пользователи
Студенты, школьники и офисные сотрудники, которым требуется удобный инструмент для оперативной фиксации конспектов, идей, списков покупок и рабочих задач на смартфоне.

## 3. Функциональные требования (MoSCoW)
### Must Have (Обязательно для MVP):
- Создание новой заметки (поля: заголовок, основной текст, автоматическая дата создания/изменения).
- Просмотр списка всех сохранённых заметок.
- Редактирование и удаление существующей заметки.
- Локальное сохранение данных (заметки не пропадают при закрытии приложения).
- Поиск заметок по ключевому слову в заголовке или тексте.

### Should Have (Желательно):
- Экспорт выбранной заметки в текстовый файл (`.txt`) в память устройства.
- Валидация ввода (запрет сохранения полностью пустой заметки).

### Could Have (Опционально):
- Сортировка заметок (сначала новые / по алфавиту).

## 4. Ограничения и стек
- **Платформа:** Android (минимальная версия Android 8.0 / API 26).
- **Среда разработки и язык:** Android Studio, Kotlin.
- **Хранение данных:** локальная БД SQLite + системный API работы с файлами Android.

## 5. Критерии приёмки
1. Пользователь может создать, отредактировать и удалить заметку без сбоев приложения.
2. После перезапуска приложения все ранее созданные заметки корректно загружаются из локальной БД.
3. Поиск мгновенно фильтрует список заметок по введённому тексту.
4. Функция экспорта сохраняет читаемый `.txt` файл с содержимым заметки.
5. Код покрыт базовыми модульными тестами (JUnit), история разработки зафиксирована в Git по дням.
