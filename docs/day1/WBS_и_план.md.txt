# Иерархическая структура работ и календарный план
**Проект:** Мобильное приложение «Заметки»  
**Команда:** Плотников Андрей, Подзоров Валерий

## 1. WBS (Декомпозиция пакетов работ)
- **1.1 Инициация и планирование (День 1–2)**
  - 1.1.1 Анализ ТЗ и формулировка требований (1.5 ч)
  - 1.1.2 Список User Stories и реестр рисков (1.5 ч)
  - 1.1.3 Иерархическая структура работ (WBS) и календарный план (2 ч)
  - 1.1.4 Настроенный Git-репозиторий, структура папок и `.gitignore` (1 ч)
- **1.2 Проектирование и ядро бизнес-логики (День 3)**
  - 1.2.1 Архитектура модуля: диаграмма классов и последовательности (2 ч)
  - 1.2.2 Модель данных `Note` и репозиторий управления заметками (2 ч)
  - 1.2.3 Логика поиска и фильтрации записей (2 ч)
- **1.3 Системное программирование и хранение данных (День 4–5)**
  - 1.3.1 Локальная база данных SQLite (создание таблиц, CRUD-запросы) (2 ч)
  - 1.3.2 Модуль файлового экспорта заметок в `.txt` через Android Storage API (2 ч)
  - 1.3.3 Обработка исключений ввода-вывода и оптимизация работы с БД (2 ч)
- **1.4 Разработка мобильного интерфейса UI (День 6)**
  - 1.4.1 Главный экран со списком заметок (`RecyclerView`) и строкой поиска (2 ч)
  - 1.4.2 Экран создания и редактирования заметки (2 ч)
  - 1.4.3 Связывание UI с бизнес-логикой и базой данных, проверка на устройстве (2 ч)
- **1.5 Тестирование и отладка (День 7)**
  - 1.5.1 Набор функциональных тест-кейсов (2 ч)
  - 1.5.2 Модульные тесты (JUnit) для бизнес-логики и поиска (2 ч)
  - 1.5.3 Ручное тестирование, отладка и оформление баг-репортов (2 ч)
- **1.6 Документирование и подготовка к защите (Дни 8–12)**
  - 1.6.1 Руководство пользователя и руководство программиста (День 8, 2 ч)
  - 1.6.2 Сборка финального релиза `v1.0` и проверка истории Git (День 9, 2 ч)
  - 1.6.3 Оформление итогового отчёта по практике (День 10–11, 2 ч)
  - 1.6.4 Презентация для защиты (5–7 слайдов) и доклад (День 12, 2 ч)

## 2. Календарный план и распределение ролей
| Этап / День | Содержание работ | Артефакт / Результат |
|---|---|---|---|
| **День 1–2** | ТЗ v1, User Stories, WBS, план, риски, настройка Git | Документы в `docs/day1/`, репозиторий, тег `day1` |
| **День 3** | Диаграммы классов, модель `Note`, бизнес-логика CRUD и поиска | Код в `src/`, диаграммы в `docs/day3/`, тег `day3` |
| **День 4–5** | Подключение SQLite, системный экспорт в `.txt`, обработка ошибок | Слой данных в `src/`, описание в `docs/day4/`, тег `day4` |
| **День 6** | Верстка экранов в Android Studio, связка UI с БД, проверка на устройстве | Рабочий прототип APK, скриншоты, тег `day6` |
| **День 7** | Тест-кейсы, написание JUnit-тестов, поиск и исправление багов | Тесты в `tests/`, баг-репорты в `docs/day7/`, тег `day7` |
| **День 8** | Руководство пользователя и программиста, черновик отчёта | Документация в `docs/day8/`, тег `day8` |
| **День 9** | Финальная отладка, проверка слияния веток, релиз | Стабильная сборка, тег `day9` и `v1.0` |
| **День 10–11** | Полное оформление отчёта и дневника практики | Готовый отчёт `.docx` |
| **День 12** | Подготовка презентации (5–7 слайдов), доклада и защита проекта | Презентация `.pptx`, успешная защита |
