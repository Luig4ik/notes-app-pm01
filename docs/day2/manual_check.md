# Ручная проверка ядра программного модуля

Проверка выполнена для слоя моделей и бизнес-логики (`Note`, `NoteRepository`, `NoteDataSource`) до интеграции с полноценным пользовательским интерфейсом.

| № | Проверяемый сценарий ядра | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Создание заметки с заполненным заголовком и текстом | Присвоен `id > 0`, заметка возвращается в `getAllNotes()` | Пройдено |
| 2 | Создание заметки из одних пробелов (`"   "`, `"\n"`) | Выброшено исключение `IllegalArgumentException` | Пройдено |
| 3 | Редактирование заметки и проверка сортировки | Текст и `updatedAt` обновлены, заметка поднялась вверх списка | Пройдено |
| 4 | Поиск по подстроке в разном регистре | Найдены совпадения в `title` и `content` без учёта регистра | Пройдено |
| 5 | Удаление заметки по ID | Метод возвращает `true`, `getNoteById` возвращает `null` | Пройдено |
