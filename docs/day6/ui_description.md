# Разработка мобильного интерфейса и прототипа (День 6)

## 1. Структура экранов и навигация
Пользовательский интерфейс выполнен в стиле Material Design 3 с вынесением всех текстовых строк на русском языке в `res/values/strings.xml` и цветовой палитры в `res/values/colors.xml`. Приложение состоит из двух основных экранов и двух системных диалогов:

- **Главный экран (`MainActivity` / `activity_main.xml`):** содержит верхнюю панель `MaterialToolbar` («Заметки»), карточку поиска `MaterialCardView` с полем `etSearch`, список `RecyclerView` (карточки `item_note.xml` с заголовком, превью текста до 2 строк и датой), текстовый блок пустого состояния `tvEmptyState` и кнопку `FloatingActionButton` («+») для создания записи.
- **Экран заметки (`NoteDetailActivity` / `activity_note_detail.xml`):** содержит `MaterialToolbar` со стрелкой возврата и динамическим заголовком («Новая заметка» / «Редактирование»), прокручиваемую область `ScrollView` с полями ввода заголовка (`etTitle`) и многострочного текста (`etContent`), а также нижнюю панель действий с кнопками «Экспорт в .txt», «Удалить» (скрыта при создании новой заметки) и «Сохранить».
- **Диалог подтверждения (`AlertDialog`):** вызывается по нажатию «Удалить» для предотвращения случайного стирания заметки.
- **Системный диалог сохранения файла (SAF):** вызывается при нажатии «Экспорт в .txt».

Навигация организована через статический фабричный метод `NoteDetailActivity.start(context, noteId)`: при передаче `noteId = -1L` открывается режим создания, при передаче реального ID — режим редактирования. Возврат на главный экран осуществляется через `finish()`, после чего срабатывает `MainActivity.onResume()`, автоматически перечитывающий актуальный список заметок из SQLite.

## 2. Связка пользовательского интерфейса с бизнес-логикой
Поиск работает в реальном времени: к полю `etSearch` привязан `TextWatcher`, который на каждое изменение текста вызывает `loadNotes(query)` → `repository.searchNotes(query)` и передаёт отфильтрованный список в `NotesAdapter.submitList(notes)`. Если список пуст, отображается `tvEmptyState` с соответствующей подсказкой («Заметок пока нет. Нажмите +, чтобы создать первую!» либо «Ничего не найдено»). В `NotesAdapter` заметки без заголовка аккуратно подписываются заглушкой «Без заголовка», а дата форматируется через `SimpleDateFormat("dd.MM.yyyy HH:mm")`.
