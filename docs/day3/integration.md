# Системное программирование и интеграция (Дни 4–5)

## 1. Слой данных на базе SQLite (`DatabaseHelper`)
Для обеспечения энергонезависимого офлайн-хранения реализован класс `DatabaseHelper` (`app/src/main/java/com/example/a1_2day/data/DatabaseHelper.kt`), наследующий стандартный `android.database.sqlite.SQLiteOpenHelper` и реализующий интерфейс `NoteDataSource`. База данных хранится в файле `notes_db.db` (версия схемы `1`) и содержит таблицу `notes`:

| Поле таблицы | Тип SQLite | Ограничения | Назначение |
|---|---|---|---|
| `id` | `INTEGER` | `PRIMARY KEY AUTOINCREMENT` | Уникальный идентификатор заметки |
| `title` | `TEXT` | `NOT NULL` | Заголовок заметки |
| `content` | `TEXT` | `NOT NULL` | Основной текст заметки |
| `updated_at` | `INTEGER` | `NOT NULL` | Время последнего изменения (мс UTC) |

Для защиты от SQL-инъекций все операции выборки, обновления и удаления (`getNoteById`, `updateNote`, `deleteNote`) выполняются через параметризованные условия (`"id = ?"`) и `ContentValues`. Для предотвращения утечек памяти и блокировок БД каждый объект `Cursor` оборачивается в блок `cursor.use { ... }`, гарантирующий автоматическое закрытие ресурса даже при возникновении исключения.

## 2. Файловый экспорт через Storage Access Framework (SAF)
Вторая системная интеграция — экспорт заметки в текстовый файл (`.txt`) — реализована в `NoteDetailActivity` с использованием системного контракта `ActivityResultContracts.CreateDocument("text/plain")`. Данный подход позволяет пользователю самостоятельно выбрать каталог сохранения (локальная память, Загрузки, облачный диск) и не требует объявления устаревших разрешений доступа к файловой системе в `AndroidManifest.xml`.

Имя файла формируется автоматически из первых 20 символов заголовка с заменой небезопасных символов на подчёркивание (или используется имя по умолчанию `note.txt`). Запись выполняется в кодировке UTF-8 через `contentResolver.openOutputStream(uri)?.use { ... }` в формате:

## 3. Проверка сохранности данных при перезапуске
- Выполнено создание, редактирование и удаление заметок через UI с последующей полной выгрузкой приложения из памяти и перезапуском.
- Все изменения корректно сохраняются в `notes_db.db` и восстанавливаются при повторном открытии `MainActivity`.
