# Обработка ошибок и граничных ситуаций

| Ситуация / Ошибка | Место обработки | Реакция приложения |
|---|---|---|
| Попытка сохранить пустую заметку или строку из пробелов | `NoteRepository.addNote` / `updateNote` → `NoteDetailActivity.saveNote` | Выбрасывается `IllegalArgumentException`; перехватывается в Activity, отображается `Toast` «Заметка не может быть пустой!», экран не закрывается. |
| Ошибка ввода-вывода при экспорте в `.txt` (нехватка места, сбой хранилища) | `NoteDetailActivity.exportContentToUri` | Исключение перехватывается в блоке `try-catch`; пользователю выводится `Toast` с текстом «Ошибка экспорта заметки» и деталями ошибки. |
| Отмена выбора папки в системном окне SAF | `createDocumentLauncher` callback | Полученный `uri` равен `null`; безопасный вызов `uri?.let {}` предотвращает падение приложения. |
| Запрос несуществующей заметки по ID | `DatabaseHelper.getNoteById` → `NoteDetailActivity.loadNoteData` | Возвращается `null`; проверка `note?.let {}` предотвращает `NullPointerException`. |
| Спецсимволы (`/`, `?`, `*`, `:`) в заголовке при экспорте | `NoteDetailActivity.startExportProcess` | Строка обрезается до 20 символов, спецсимволы заменяются на `"_"` через регулярное выражение; для пустого заголовка задаётся `note.txt`. |
