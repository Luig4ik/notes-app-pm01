# Баг-репорты и исправление дефектов

| ID | Серьёзность | Описание дефекта | Шаги воспроизведения | Ожидаемо / Фактически | Статус |
|---|---|---|---|---|---|
| BUG-01 | Critical | Сохранение заметки, состоящей только из пробелов и переносов строк | 1. Открыть создание заметки.<br>2. Ввести `"   "` в заголовок.<br>3.
